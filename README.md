# Proyecto de Eventos

## Descripción
Este proyecto es una aplicación para la gestión de eventos. Permite a los usuarios crear, editar y eliminar eventos, así como ver una lista de eventos próximos.

## Gestión de Recursos
- **Eventos**: Permite la creación, edición, eliminación y visualización de eventos.
- **Ocupaciones**: Gestiona las ocupaciones de los espacios físicos, permitiendo reservar y liberar espacios.
- **Espacios Físicos**: Administra los espacios físicos disponibles para eventos y ocupaciones.
- **Puntos de Interés**: Permite añadir y gestionar puntos de interés relacionados con los eventos y espacios físicos.



## Requisitos del Sistema
- Java 8 o superior
- Eclipse IDE
- Base de datos MySQL

## Instalación
1. Clona el repositorio:
    ```bash
    git clone https://github.com/elmanueh/eventos.git
    ```
2. Importa el proyecto en Eclipse:
    - Abre Eclipse.
    - Selecciona `File > Import`.
    - Elige `Existing Projects into Workspace` y selecciona la carpeta del proyecto clonado.
3. Crea una base de datos MySQL llamada `eventos`.
4. Configura el archivo `application.properties` con tus credenciales de MySQL.
